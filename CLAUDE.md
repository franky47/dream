## TypeScript Type Discipline

**The `typescript-advanced-types` skill is mandatory for all TypeScript work in this project.** Load it before writing or reviewing any `.ts` file. Always use Zod to parse & validate external data coming into the program, and infer from schemas.

## Conventions

- Tests are co-located with source files (`foo.test.ts` next to `foo.ts`).
- Error handling is done with `errore`, use its skill for details.
- Always run the `bun check` command to verify your work, never use bespoke commands. If the check command misses something, suggest an improvement.
